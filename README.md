## Управление таблицами

Запустите базу командой `uv run database`.

- `create_table <имя> <столбец:тип> ...` — создать таблицу (ID добавляется автоматически)
- `list_tables` — показать список таблиц
- `drop_table <имя>` — удалить таблицу
- `help` — справка, `exit` — выход

Пример:

    create_table users name:str age:int is_active:bool
    Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool


## CRUD-операции

- `insert into <таблица> values (...)` — добавить запись (ID генерируется автоматически)
- `select from <таблица> [where <столбец> = <значение>]` — прочитать записи
- `update <таблица> set <столбец> = <значение> where <условие>` — обновить записи
- `delete from <таблица> where <условие>` — удалить записи
- `info <таблица>` — информация о таблице


## Надёжность и декораторы

- `handle_db_errors` — централизованная обработка исключений с понятными сообщениями
- `confirm_action` — подтверждение перед опасными операциями (удаление записей и таблиц)
- `log_time` — замер времени выполнения операций
